# 카카오 위치 검색 연결

1. https://developers.kakao.com 에서 앱을 만들거나 기존 앱을 선택한다.
2. 카카오맵 → 사용 설정을 켠다. 무료 쿼터 적용 앱인지 확인하고 유료 API 사용은 활성화하지 않는다. 현재 정책은 개발자 계정 기준 첫 활성화 앱에만 무료 쿼터를 제공한다.
3. 앱의 REST API 키를 복사해 프로젝트 루트 `.env`에 `KAKAO_REST_API_KEY=발급받은키`로 직접 저장한다. JavaScript 키나 Admin 키를 사용하지 않는다. 기존 .env 내용은 유지한다.
4. 무료 쿼터 적용 및 유료 API 미사용을 확인한 경우에만 `KAKAO_FREE_ONLY_CONFIRMED=true`를 추가한다. 이 값은 계정 설정을 자동 검증하거나 변경하지 않는다.
5. 화면을 새로고침하고 “잠실역에서 4명 파티게임 추천해줘”를 입력한다. 후보가 여러 개면 주소를 보고 “2번”처럼 답한다.

키는 서버에서만 읽으며 Git, LLM, 화면 답변에 포함하지 않는다. 장소 변경 요청 시 추출한 장소명/주소만 카카오에 전송한다. 키워드 검색을 먼저 하고 결과가 없을 때 주소 검색을 수행한다. 요청당 최대 2회이며 자동 재시도·주기 호출·유료 전환은 없다. 인증·쿼터·연결 오류 시 기존 위치를 새 위치인 것처럼 대신 사용하지 않는다. 위치 변경 없이 후속 추천을 요청하면 이미 선택한 좌표를 재사용한다.

API 연동과 오류/후보 선택 처리는 모의 응답으로 검증했다. 실제 API 호출 검증은 키 설정 후 필요하다. 현재 위치 검색은 카카오 API를 사용하지만 지도 화면 삽입 SDK는 추가하지 않았다.
